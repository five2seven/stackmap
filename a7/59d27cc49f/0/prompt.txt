Context:

- StackMap is running on Docker/OpenMediaVault.
- Portainer is connected to the local Docker socket.
- `/api/endpoints` returns:

```json
{
  "Id": 1,
  "Name": "local",
  "Type": 1,
  "ContainerEngine": "",
  "URL": "unix:///var/run/docker.sock",
  "Status": 1
}
```

Current bug:

- StackMap filters environments with:
  `containerEngine.toLowerCase() === 'docker'`

- Type 1 + blank ContainerEngine => accepted

- existing discovery/import behavior remains unchanged
